Git Hub For Multiple User(Branches)
###################################

------------------------------------------------------------------------------------------------------------


1. Check Node.js
----------------
Open CMD / Terminal:
--------------------

node -v
npm -v

2. Create React Project
-----------------------

npm create vite@latest my-react-app

Select:
-------

Project name: my-react-app
Framework: React
Variant: JavaScript

Or use the direct command:
--------------------------

npm create vite@latest my-react-app -- --template react

3. Go inside the project
------------------------

cd my-react-app

4. Install dependencies
-----------------------

npm install

5. Start the development server
-------------------------------

npm run dev

------------------------------------------------------------------------------------------------------------

Step 01
-------

Create Repository in your Git Hub with ReadMe, Public

Step 02
-------

Open Your Vs Code with Project Folder & Open Git Bash(or Termminal)
------------------------------------------------------------------- 

git remote add origin https://github.com/selvakumarj1807/multipleUser.git

Open your Git Hub via chrome & Create Branches
----------------------------------------------

dev & base code

Show all local branches
-----------------------

git branch  

Show all remote branches
------------------------

git branch -r 

Show both local + remote branches
---------------------------------

git branch -a

git branch -M base-code

git add .

git commit -m "Initial Commit"

git push origin base-code -f

If Have a error like cannot change Git Hub Another Login Then Follow Below step
-------------------------------------------------------------------------------

Sign Out & Sign In Your Git Hub Account

git config --global user.name "Your Name"

git config --global user.email "you@example.com"

git remote -v

git config --global user.name

git config --global user.email

git branch

git push -u origin base-code -f

Then Check Your Git Hub Repository (base-code)

Step 03
-------

Make Pull Request for base-code to dev branches via Git Hub use Chrome
----------------------------------------------------------------------

Contribute --> Open Pull Request -- dev to base-code --> Then have There isn’t anything to compare.
dev and base-code are entirely different commit histories.

git pull origin dev

Then have fate error its Okay.

git pull origin dev --allow-unrelated-histories

Then have a error - CONFLICT (add/add): Merge conflict in README.md. Then Open VS Code Source Control --> Accept Current Changes & Merge Changes(Click +) & Publish or Commit Changes

git commit -m "Merge Conflict Resolve"

git push -u origin base-code

Then Go to Your Repository via Git Hub use Chrome 
-------------------------------------------------

Contribute --> Open Pull Request -- dev to base-code --> Create Pull Request --> Merge Pull Request --> Confirm Merge

Then Refresh your Branches
