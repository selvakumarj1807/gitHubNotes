Step01 - Create Git Repository in GitHub
----------------------------------------

Step02 - CMD
------------

git remote add origin https://github.com/infinite-techies/angular-project.git

Step03 - Add Branch in GitHub(base-code, dev)
---------------------------------------------

Step04 - check current branch in your project - CMD
---------------------------------------------------

git branch

git pull

git branch

Step05 - change branch - master to base-code - CMD
--------------------------------------------------

git branch -M base-code

git branch

git add .

git commit -m "Initial Commit"

git push origin base-code -f

Step06 - pull request base-code to dev branch in GitHub
-------------------------------------------------------

refresh the page and change or check the branches.

Contribute --> click Open pull reguest

select one branch to another branch(Change main to dev Only)


Step07 - CMD
------------

git pull origin dev

git pull origin dev --allow-unrelated-histories

Step08 -- Create common commit for dev branch in VS Code
--------------------------------------------------------

click gitRepositry --> Merge Changes Click + Symbol --> Publish Branch

Step09 - Merge
--------------

git commit -m "Merge Conflict Resolved"

git push origin base-code

Step10 - Now Step06 can pull request base-code to dev branch in GitHub
----------------------------------------------------------------------

Contribute --> click Open pull reguest

select one branch to another branch(Change main to dev Only)

Add Description

click the --> create pull request

(Merge base-code to dev)

click the --> Merge pull request --> Confirm
